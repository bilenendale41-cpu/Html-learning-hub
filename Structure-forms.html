Semantic HTML Elements

Semantic elements describe the meaning and purpose of webpage content.

<header>

Represents introductory content.

<nav>

Contains navigation links.

<main>

Contains the main content.

<section>

Groups related content.

<article>

Contains independent content.

<aside>

Contains additional related content.

<footer>

Represents the bottom part of content.

<figure>

Groups media and related content.

<figcaption>

Creates a caption for a figure.

Table Elements

Common HTML Table Elements
Element Definition
<table> Creates a table.
<tr> Creates a table row.
<th> Creates a table heading.
<td> Creates a table data cell.
<thead> Groups table header rows.
<tbody> Groups the main table rows.
<tfoot> Groups table footer rows.

Form Elements

<form>

Creates a form.

<label>

Provides a label for a form control.

<input>

Creates an input field.

<textarea>

Creates a multi-line input.

<select>

Creates a drop-down list.

<option>

Creates an option.

<optgroup>

Groups related options.

<button>

Creates a button.

<fieldset>

Groups related form controls.

<legend>

Provides a title for a fieldset.

Important Form Attributes

required

The user must enter a value.

disabled

Disables a form control.

readonly

Makes a field unable to be edited.

placeholder

Shows a hint inside an input.

checked

Selects a checkbox or radio button by default.
