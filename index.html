Basic HTML Elements

HTML stands for HyperText Markup Language. HTML is used to create the structure of webpages.

Document Elements

<!DOCTYPE html>

Tells the browser that the document uses HTML5.

<html>

The root element of an HTML document.

<head>

Contains information about the webpage.

<title>

Defines the title shown in the browser tab.

<body>

Contains the visible content of the webpage.

<meta>

Provides information about the HTML document.

<link>

Connects the HTML document to another resource, such as a CSS file.

Text and Basic Elements

<h1> - <h6>

Creates headings. H1 is the most important heading.

<p>

Creates a paragraph.

<br>

Creates a line break.

<hr>

Creates a horizontal/thematic line.

<div>

Creates a block-level container.

<span>

Creates an inline container for text or other content.

Links and Images

<a>

Creates a hyperlink.

<a href="page.html">Visit</a>

<img>

Displays an image.

<img src="photo.jpg" alt="Photo">

Global Attributes

Global attributes can be used on many different HTML elements.

id

Gives an element a unique identifier.

<p id="intro">Hello</p>

class

Gives an element one or more classes. CSS and JavaScript can use classes.

<p class="important">Hello</p>

style

Adds CSS directly to an element.

<p style="color: blue;">Hello</p>

title

Provides extra information, often shown as a tooltip.

<p title="More information">Hello</p>

lang

Specifies the language of the content.

<html lang="en">

hidden

Hides an element from the page.

<p hidden>Hidden text</p>

tabindex

Controls keyboard navigation order.

<button tabindex="0">Click</button>

contenteditable

Allows the user to edit content directly.

<p contenteditable="true">Edit me</p>

data-*

Stores custom data on an HTML element.

<div data-id="10"></div>

Basic HTML Example

<!DOCTYPE html>

<html lang="en">

<head>
    <title>My Page</title>
</head>

<body>

    <h1>Hello World</h1>

    <p>This is my webpage.</p>

</body>

</html>
