Text Formatting Elements

These elements are used to format text or give text a special meaning.

<b>

Makes text bold.

<strong>

Shows important text.

<i>

Displays italic text.

<em>

Emphasizes text.

<u>

Underlines text.

<mark>

Highlights text.

<small>

Displays smaller text.

<del>

Shows deleted text.

<ins>

Shows inserted text.

<sub>

Creates subscript text.

<sup>

Creates superscript text.

Quotation and Code Elements

<blockquote>

Used for a long quotation.

<q>

Used for a short quotation.

<code>

Displays computer code.

<pre>

Keeps spaces and line breaks.

<kbd>

Represents keyboard input.

<abbr>

Defines an abbreviation.
