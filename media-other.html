Media Elements

HTML provides elements for images, audio, video and other content.

<audio>

Adds audio to a webpage.

<video>

Adds video to a webpage.

<source>

Provides a media source.

<track>

Provides subtitles or captions.

<picture>

Allows different images to be used.

<iframe>

Embeds another webpage.

<canvas>

Provides an area for JavaScript graphics.

<map>

Creates an image map.

<area>

Creates a clickable area in an image map.

ARIA Attributes

ARIA means Accessible Rich Internet Applications.

ARIA attributes help make webpages more accessible to people who use screen readers and other assistive technologies.

aria-label

Gives an element an accessible name.

aria-label="Close menu"

aria-hidden

Tells assistive technology to ignore an element.

aria-hidden="true"

aria-live

Tells screen readers about changing content.

aria-live="polite"

aria-expanded

Shows whether something is expanded or collapsed.

aria-expanded="false"

aria-controls

Identifies the element controlled by another element.

aria-controls="menu"

aria-labelledby

Connects an element to another element that labels it.

aria-labelledby="title"

aria-describedby

Connects an element to a description.

aria-describedby="help"

aria-current

Identifies the current item in a set.

aria-current="page"

aria-disabled

Indicates that an element is disabled.

aria-disabled="true"

aria-required

Indicates that an input is required.

aria-required="true"

aria-selected

Indicates that an item is selected.

aria-selected="true"
